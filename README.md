# 信じる？裏切る？ 人間関係シミュレーター
### ゲーム理論「繰り返し囚人のジレンマ」で可視化する、あなたの思考のクセと意思決定パターン

> **「自分が価値を置くものに向かって こつこつ努力する姿ほど 素晴らしいものはない」**  
> — テラオカ電子の自由探究ゼミ（Teraoka-Denshi）

## 1. アプリ概要とねらい

高校生活において、友人関係、部活動、文化祭の準備、勉強や課題の分担など、私たちは日常的に**「他者を信じて協力するか、それとも自分だけの利益や安全を優先して裏切る（手を抜く・独占する）か」**という選択を無意識に行っています。

本アプリケーションは、ゲーム理論の金字塔である**「繰り返し囚人のジレンマ（Iterated Prisoner's Dilemma）」**をベースに設計された、高校生のための**自己客観化・探究学習教材**です。

### 本教材のコアな目的
1. **思考のクセの可視化**: 感情や直感で行っている日常の対人行動を、データ（初期信頼度・報復期間・搾取耐性）として客観視する。
2. **ゲーム理論の数理的理解**: ナッシュ均衡、パレート最適、割引因子 $\delta$ による「協調の創発」を、体験を通じて学ぶ。
3. **長期的な信頼構築の知恵**: ロバート・アクセルロッドの「しっぺ返し戦略」と勝因4原則（善良・報復・寛容・明快）を理解し、実生活のコミュニケーションやアンガーマネジメントに活かす。

## 2. ゲーム理論と囚人のジレンマの数学的解説

### (1) 利得（スコア）マトリクスと成立条件
囚人のジレンマゲームにおいて、プレイヤーAとプレイヤーBの選択に応じた利得は以下のように定義されます。

| あなた ＼ 相手 | 相手：協力（Cooperate） | 相手：裏切り（Defect） |
| :--- | :---: | :---: |
| **あなた：協力（Cooperate）** | **(R, R) = (3, 3)**<br>相互協力の報酬 | **(S, T) = (0, 5)**<br>搾取される（お人好し） |
| **あなた：裏切り（Defect）** | **(T, S) = (5, 0)**<br>搾取の誘惑（独り勝ち） | **(P, P) = (1, 1)**<br>相互裏切りの罰 |

ここで、各利得は以下の記号で表されます：
* $T$ (Temptation to defect): 自分だけ裏切る誘惑の利得（**5点**）
* $R$ (Reward for mutual cooperation): 相互協力の報酬（**3点**）
* $P$ (Punishment for mutual defection): 相互裏切りの罰（**1点**）
* $S$ (Sucker's payoff): 自分だけ協力して裏切られたときの報い（**0点**）

#### 数学的成立条件
囚人のジレンマとして成立するためには、厳密に以下の2つの不等式を満たす必要があります。

1. **強支配の順序条件**:
   $$T > R > P > S$$
   本アプリの設定値では $5 > 3 > 1 > 0$ であり、成立しています。
2. **協調の社会的是正条件**:
   $$2R > T + S$$
   （裏切りと協力を交互に繰り返して山分けする平均利得 $(T+S)/2$ よりも、双方が恒常的に協力し合う利得 $R$ の方が高いこと）  
   本アプリでは $2 \times 3 = 6 > 5 + 0 = 5$ であり、成立しています。

---

### (2) ナッシュ均衡とパレート最適の悲劇
1回限りのゲームにおいて、各プレイヤーの合理的な意思決定を追跡します。

* **相手が「協力」してきた場合**: 自分は「協力（3点）」よりも「裏切り（5点）」を選んだ方が得をする。
* **相手が「裏切り」してきた場合**: 自分は「協力（0点）」よりも「裏切り（1点）」を選んだ方が得をする。

すなわち、相手の手が何であれ、自分にとって常に最大利得をもたらす選択肢は「裏切り」となります。これを**強支配戦略（Strictly Dominant Strategy）**と呼びます。

双方が合理的に利己的判断を下すと、必然的に結果は $(裏切り, 裏切り) = (1, 1)$ に固定されます。このとき、どちらのプレイヤーも単独で選択を変えても利得が増えないため、これが唯一の**ナッシュ均衡（Nash Equilibrium）**となります。

しかし、もし双方が協力していれば $(協力, 協力) = (3, 3)$ という、誰の利得も損なわずに全員が得をする**パレート最適（Pareto Optimality）**が達成できたはずです。  
**「個人の合理的な利己心の追求が、集団全体の最悪の結果を招く」**――これこそが囚人のジレンマの構造的悲劇です。

---

### (3) 繰り返しゲームと将来の割引因子 $\delta$（フォーク定理）
一回限りのゲームでは裏切りが不可避ですが、**「明日以降も関係が継続する」**という繰り返しゲーム（Iterated Prisoner's Dilemma）では、協調が合理的な均衡として創発します。

将来得られる利得の現在価値を割り引く係数を $\delta$（$0 < \delta < 1$、関係が明日も続く確率や将来を重視する度合い）とします。

#### ① 永続的に協力し続ける場合の期待利得 $V_{\text{coop}}$:
等比数列の総和の公式より：
$$V_{\text{coop}} = R + \delta R + \delta^2 R + \dots = \sum_{t=0}^{\infty} \delta^t R = \frac{R}{1 - \delta}$$

#### ② 初手で裏切り、以降は相手の報復によって相互裏切りに陥る場合の期待利得 $V_{\text{defect}}$:
$$V_{\text{defect}} = T + \delta P + \delta^2 P + \dots = T + \sum_{t=1}^{\infty} \delta^t P = T + \frac{\delta P}{1 - \delta}$$

#### ③ 協力関係が維持される条件:
裏切るインセンティブが生じない条件は $V_{\text{coop}} \ge V_{\text{defect}}$ です。これを $\delta$ について解くと：
$$\frac{R}{1 - \delta} \ge T + \frac{\delta P}{1 - \delta}$$
$$R \ge T(1 - \delta) + \delta P = T - \delta(T - P)$$
$$\delta(T - P) \ge T - R$$
$$\delta \ge \frac{T - R}{T - P}$$

本アプリの利得パラメータ（$T=5, R=3, P=1$）を代入すると：
$$\delta \ge \frac{5 - 3}{5 - 1} = \frac{2}{4} = 0.5$$

これは、**「明日も関わりが続く確率や将来を重視する度合い（$\delta$）が 50% 以上であるならば、協調関係を維持することが数学的に最も得である」**ことを意味します（フォーク定理の一形態）。

### (4) ロバート・アクセルロッドのトーナメントと勝因4原則
1980年、政治学者ロバート・アクセルロッド（Robert Axelrod）は世界中の一流数学者やゲーム理論家に呼びかけ、コンピュータプログラム同士を戦わせる「繰り返し囚人のジレンマ・トーナメント」を開催しました。

優勝したのは、アナトール・ラパポートが提出した、最も単純な戦略**「しっぺ返し（Tit-for-Tat）」**でした。アクセルロッドは高得点を収めた優秀な戦略の共通項を分析し、以下の**「4つの勝因原則」**を導き出しました：

1. **善良さ（Nice）**: 自分からは先に裏切らないこと。無用な争いや敵対関係の連鎖を未然に防ぎます。
2. **報復心（Retaliatory）**: 相手に裏切られたら、即座に毅然と裏切り返すこと。「搾取できるカモ」と思われるのを防ぎます。
3. **寛容さ（Forgiving）**: 相手が協調に戻ったら、過去の裏切りを根に持たず即座に協調を再開すること。泥沼の仕返し合戦を終結させます。
4. **明快さ（Clear）**: 自分の行動パターンが相手にとって予測しやすいこと。相手に疑心暗鬼を生じさせず、協調関係を安定させます。

## 3. アプリの構成と仕様

### (1) 高校生向け5大対戦シナリオ
高校生が身近に体験するリアルなジレンマを5つのシナリオとして収録しています。

1. **文化祭の備品シェア（学校行事）**:
   * 協調: 他クラスと大工道具や機材を時間通りに融通し合い、学校全体を盛り上げる。
   * 裏切り: 自クラスの企画完成度を優先し、人気工具を教室内に隠して独占する。
2. **探究・グループワークの分担（探究学習）**:
   * 協調: 休日返上で担当パートを真面目に調べ、質の高い発表スライドを共有する。
   * 裏切り: 部活や遊びを優先してサボり、他人の完成資料に名前だけ連名する（フリーライダー）。
3. **定期考査前のノート・情報共有（勉強・考査）**:
   * 協調: 自分がまとめた図入りの分かりやすいノートを惜しみなく見せ合う。
   * 裏切り: 相手のまとめだけスマホで撮らせてもらい、自分の特選プリントは隠す。
4. **部活動のグラウンド整備＆片付け（部活動）**:
   * 協調: 猛暑のハード練習後でも、全員で声を掛け合って道具の片付け・掃除を素早く終わらせる。
   * 裏切り: 「足がつった」と日陰で休み、他の部員にきつい片付けを押し付ける。
5. **クラスLINE・連絡網の集約（日常・SNS）**:
   * 協調: 委員の負担を思いやり、面倒なアンケートにも即座に回答する。
   * 裏切り: 「誰かが答えるだろう」と既読スルーして放置し、委員を困らせる。

---

### (2) 対戦相手（Bot）の4つのアルゴリズム仕様
ユーザーは正体を知らされないまま、以下の4名のBotと連続して対戦します（各10ターン、合計40ターン設定）。

| 相手コード | 正体（アルゴリズム名） | 行動ロジック | 高校生活でのアナロジー |
| :--- | :--- | :--- | :--- |
| **生徒 A** | **しっぺ返し (Tit-for-Tat)** | 初手は必ず協調。以降は相手が直前に出した手をそのまま返す。 | 公平で筋の通った友人。やられたら怒るが、謝ればすぐ水に流す。 |
| **生徒 B** | **お人好し (Always Cooperate)** | 相手が何をしようと、永久に協調を出し続ける。 | 頼まれたら断れない心優しい友人。搾取の誘惑をテストする。 |
| **生徒 C** | **執念深い (Grudger / トリガー)** | 最初は協調するが、一度でも裏切られたら永久に裏切り続ける。 | 普段は優しいが、一度裏切られたら絶対に口を利かないタイプ。 |
| **生徒 D** | **気まぐれ (Random)** | 悪気や意図はなく、50%の完全ランダムで手を出す。 | 気分屋で読めない相手。過剰な疑心暗鬼（深読み）を暴く。 |

---

### (3) 自己分析指標の計算ロジック
全対戦ログから、ユーザーの心理傾向を以下の3つの指標で数値化します。

1. **初期信頼度（First Contact Trust）**:
   * **計算式**: $\frac{\text{全4名の相手に対する第1ターンで協調を選んだ回数}}{4} \times 100 \ (\%)$
   * **分析**: 75%以上＝オープンな性善説、50%＝バランス・観察型、30%以下＝警戒・防衛型。
2. **許容度と報復期間（Anger Management）**:
   * **計算式**: 相手に裏切られた直後のターンから、自分が連続して裏切りを出したターン数の平均値。
   * **分析**: 1.0ターン以下＝即座の切り替え（寛容）、2.0ターン前後＝毅然とした制裁、3.0ターン以上＝執念深い長期泥沼型。
3. **搾取性・誘惑への耐性（Temptation Resistance）**:
   * **計算式**: 「お人好しBot（生徒B）」との対戦後半（第5〜10ターン）において、ユーザーが裏切りを選んだ割合（%）。
   * **分析**: 20%以下＝高潔なフェアプレイ精神、60%以下＝プラグマティスト、70%以上＝完全搾取テイカー。

## 4. 探究学習・授業での指導案（ワークシート活用例）

総合的な探究の時間、情報I、公民科（公共・倫理・政治経済）等での授業展開例です。

### 授業フロー（50分モデル）
1. **導入（10分）**: シナリオ「文化祭の備品シェア」を例に、日常の損得と信頼について問いかける。
2. **個人シミュレーション（15分）**: 生徒各自がスマートフォンまたはPCでアプリを実行し、40ターンをプレイする。
3. **種明かし＆データ分析（10分）**: 相手の正体を開示し、自分のレーダーチャートと3大指標を確認する。
4. **グループ対話＆内省（15分）**: 診断レポート（`.txt`）を保存し、以下の問いについてペアまたはグループで議論する。

### 探究ノート・振り返りの問い
* **問い 1**: 生徒B（お人好し）だと分かったとき、あなたはどう感じ、なぜその選択肢を選びましたか？
* **問い 2**: 生徒C（執念深い）に一度裏切ってしまった後、ゲームはどうなりましたか？ そのとき何を感じましたか？
* **問い 3**: 現実の友人関係や部活動で、あなたはこのシミュレーターと同じ「報復の長さ」や「初手信頼」をとっていますか？
* **問い 4**: アクセルロッドの勝因4原則（善良・報復・寛容・明快）のうち、今後の学校生活に最も活かしたいものはどれですか？

## 5. システム構成・動作要件

* **ファイル形式**: 完全単一HTMLファイル（`index.html` 内に HTML, CSS, JavaScript を統合）
* **通信仕様**: 完全クライアントサイド動作（外部サーバー通信なし・ユーザー行動ログの外部送信なし・プライバシー完全保護）
* **ブラウザ要件**: Google Chrome, Safari, Microsoft Edge, Firefox 等のモダンブラウザ対応（スマートフォン・タブレット・PC両対応、完全レスポンシブ）
* **外部ライブラリ (CDN)**:
  * Tailwind CSS（スタイリング・ダークモード）
  * Chart.js（5次元レーダーチャート・相手別スコア比較バーグラフ）
  * KaTeX（ゲーム理論・フォーク定理の数式描画）
  * canvas-confetti（全対戦完了時の演出）
  * Web Audio API（シンセサイザー効果音生成・オフライン完結）

## 6. Vercelへのデプロイ手順

本アプリは完全な静的Webアプリケーション（HTML/CSS/JS）であり、VercelとGitHubを連携することで、わずか1分でインターネット上に無料公開できます。

### デプロイの流れ
1. **GitHubリポジトリ**: 本リポジトリ（`ThePrisonersDilemma`）を GitHub にプッシュします。
2. **Vercelにサインイン**: [Vercel公式サイト](https://vercel.com/) にアクセスし、GitHubアカウントでログインします。
3. **新規プロジェクトの作成 (Add New... > Project)**:
   * リポジトリ一覧から `ThePrisonersDilemma` を選択し、**「Import」** をクリックします。
4. **設定の確認**:
   * **Framework Preset**: `Other`（`vercel.json` が同梱されているため自動認識されます）
   * **Root Directory**: `./`（デフォルトのまま）
   * **Build and Output Settings**: ビルドコマンド不要（空欄でOK）
5. **デプロイの実行**:
   * **「Deploy」** ボタンを押すと、数秒でデプロイが完了し、公開URL（例: `https://the-prisoners-dilemma-xxx.vercel.app`）が発行されます。
